SQL inicial

create table public.boloes ( id uuid primary key default gen_random_uuid(), titulo text not null, loteria text not null, valor_cota text not null, data_sorteio date not null, data_pagamento date not null, pix text not null, slug text unique not null, descricao text, created_at timestamp with time zone default now() ); create table public.participantes ( id uuid primary key default gen_random_uuid(), bolao_id uuid references public.boloes(id) on delete cascade, nome text not null, contato text, status text default 'pendente', created_at timestamp with time zone default now() ); create table public.jogos ( id uuid primary key default gen_random_uuid(), bolao_id uuid references public.boloes(id) on delete cascade, concurso text not null, dezenas text not null, valor text, observacoes text, created_at timestamp with time zone default now() );

Como hospedar grátis

Passo a passo curto para publicar o app sem pagar.

Cloudflare Pages
  1. Crie uma conta no GitHub e outra na Cloudflare Pages.
  2. Suba este arquivo HTML para um repositório no GitHub.
  3. Na Cloudflare, escolha Workers & Pages e depois Create application.
  4. Importe o repositório, use a branch main, comando exit 0 e diretório de saída ..
  5. Depois do deploy, você receberá um endereço no formato seu-projeto.pages.dev.

Se quiser domínio próprio depois, você pode apontar um domínio para a Cloudflare. Se quiser backend gratuito, conecte o app ao Supabase.
